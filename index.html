Northgate Platform Handbook

Deploy, rollback and on-call runbooks for the Northgate Labs platform team.

Deploy a service

  1. Confirm the release tag has a green tests check on main.
  2. Post the deploy notice in the platform channel with the tag and the owner.
  3. Run the deploy from the release pipeline and watch the health dashboard for ten minutes.

Roll back a deploy

  1. Roll back when error rate stays above 2 percent for five minutes after a deploy.
  2. Redeploy the previous release tag from the pipeline; never patch on the host.
  3. Post the rollback notice and open an incident ticket with the two tags.
